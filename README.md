📘 Santander Bootcamp Ciência de Dados com Python.
📌 Sobre o Bootcamp
O Santander Bootcamp Ciência de Dados com Python e AWS é uma iniciativa do Santander Open Academy em parceria com a Digital Innovation One (DIO).
O programa oferece formação gratuita e online em ciência de dados, com foco em Python, análise de dados, machine learning e fundamentos de computação em nuvem (AWS).

🎯 Objetivos do Bootcamp
- Desenvolver habilidades em Python para ciência de dados.
- Aprender conceitos de estatística aplicada, análise exploratória e visualização de dados.
- Implementar modelos de machine learning.
- Introduzir noções de computação em nuvem (AWS) aplicadas à ciência de dados
